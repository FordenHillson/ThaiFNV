# xTranslator — โหลดมาวางในโฟลเดอร์นี้

## แหล่งโหลด (เลือกอันใดอันหนึ่ง)
- **Nexus Mods (ปัจจุบัน, แนะนำ):** https://www.nexusmods.com/starfield/mods/313
  - เวอร์ชันล่าสุด: **xTranslator 1.7.x** (อัปเดต 23 ต.ค. 2026)
  - โหลดไฟล์ zip ลงในโฟลเดอร์นี้ แล้ว extract
- GitHub (ซอร์ส/คู่มือ): https://github.com/MGuffin/xTranslator

## หมายเหตุสำหรับ FNV
- xTranslator เป็นเครื่องมือ multi-game ตัวเดียว ใช้กับ FNV ได้
- ตัว exe สำหรับ FNV = **`fonvTranslator.exe`** (หรือ `xTranslator.exe` แล้ว rename เป็น `fonvTranslator.exe`)
- ใช้ใน "Esp mode" เพื่อ load `FalloutNV.esm` และ export/import ข้อความ
- ไม่จำเป็นต้องวางในโฟลเดอร์เกม — รันจากโฟลเดอร์นี้ได้ ระบุ path ไป `Data\` ของเกมตอนใช้

## หลังโหลดเสร็จ
- Extract zip ให้ไฟล์ exe + โฟเดอร์เครื่องมืออยู่ตรงในโฟลเดอร์นี้
- บอก agent ได้ว่าโหลดเสร็จแล้ว
