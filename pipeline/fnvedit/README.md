# FNVEdit — โหลดมาวางในโฟลเดอร์นี้

## แหล่งโหลด
- **Nexus Mods (แนะนำ):** https://www.nexusmods.com/newvegas/mods/128
  - เวอร์ชันล่าสุด: **FNVEdit 4.x**
  - โหลดไฟล์ zip ลงในโฟลเดอร์นี้ แล้ว extract
- หน้าทางการ (คู่มือ): https://fnvedit.readthedocs.io/

## หมายเหตุ
- FNVEdit = เครื่องมือ edit .esm/.esp ระดับ record (ใช้ verify / แก้ข้อความ / ตรวจ conflict)
- ไม่จำเป็นต้องวางในโฟลเดอร์เกม — รันจากโฟลเดอร์นี้ได้ ระบุ path ไป `Data\` ตอนเปิด
- ตอนแรก run จะถาม path ของ game data → ชี้ไปที่
  `D:\SteamLibrary\steamapps\common\Fallout New Vegas\Data`

## หลังโหลดเสร็จ
- Extract zip ให้ `FNVEdit_4.exe` + โฟเดอร์อยู่ตรงในโฟลเดอร์นี้
- บอก agent ได้ว่าโหลดเสร็จแล้ว
