# Thai word break — 2026-10-30

## ปัญหา
เกมตัดบรรทัดที่ช่องว่าง และใส่ `-` กลางรันที่ไม่มีวรรค  
→ `สามารถเป-` / `ลี่ยนได้…`

CP874 ไม่มี ZWSP

## วิธีแก้
แทรกช่องว่าง ASCII ที่ขอบคำ (`pipeline/thai_wordbreak.py`)

| โหมด | พฤติกรรม |
|------|----------|
| `sparse` (default, `--limit 28`) | ใส่วรรคเมื่อรันไทยยาวเกิน N ตัว — วรรคน้อย อ่านใกล้เดิม |
| `dense` | วรรคระหว่างทุกคำจากพจนานุกรม |

รวมกับ precompose:

```text
python pipeline/esp_apply_thai.py path\ThaiFNV_Test.esp --in-place
```
